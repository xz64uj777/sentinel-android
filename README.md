## Current Alpha Features

- Device integrity checks
- Root / debugger / emulator detection
- Installed-app and permission scanning architecture
- Accessibility and overlay risk checks
- Local security scoring
- Local VPN service foundation
- Monitor and firewall modes
- Threat/event logging architecture
- Lockdown-mode foundation
